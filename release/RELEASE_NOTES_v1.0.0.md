# 術科題目轉圖片 v1.0.0

第一個正式版本。把工科技藝競賽「05 電腦軟體設計」的術科 PDF 依題目切割，每一題輸出成一張長圖片。

## 下載與使用

1. 下載 `PdfQuestionSplitter_v1.0.0.zip` 並解壓縮。
2. 執行 `PdfQuestionSplitter.exe`，加入 PDF、選擇輸出資料夾，按「開始轉換」。

## 系統需求

- Windows 10 / 11（已內建 .NET Framework 4.7.2 以上）
- 已安裝「中文(繁體，台灣)」語言（Windows 內建 OCR 用來辨識題目標題）

## 功能

- 自動找出「試題1」「題目二」「第三題」等標題，從一題切到下一題
- 跨頁的題目會上下拼接成一張圖，並去除頁碼與空白邊
- 文字型 PDF 與掃描檔都適用
- 可拖曳檔案、批次轉換多個 PDF，並產生轉換紀錄
- 命令列批次模式：`PdfQuestionSplitter.exe --out 輸出資料夾 [--dpi 150] [--nosub] 檔案或資料夾 ...`

## 已測試

- 99～114 學年度共 16 份術科 PDF，正確切出 96 題

## 已知限制

- 檔名中的題目名稱來自 OCR，少數字可能辨識錯誤（圖片內容不受影響）
